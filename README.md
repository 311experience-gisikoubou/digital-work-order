## 動作確認方法

### 重要：確認対象

このブランチの正式な入口ファイルは `index.html` です。
過去に使っていた旧HTML名は、現在の入口として案内しません。

公開環境の有無は、このリポジトリ内のファイルだけでは確認できません。
ローカル確認では、作業ブランチのファイルを取得して `index.html` をブラウザで開いてください。

1. 作業ブランチの内容を取得する
2. `index.html` をブラウザで開く
3. **Ctrl+F5（強制再読み込み）を必ず実行**してから確認する

### 保存と外部通信

- 注文データは現在メモリ保持です。ページ再読み込み時に消えます。
- 手書き線とクラスプ位置は localStorage に保存されます。
- 納期カレンダーは日本の祝日判定のため `https://holidays-jp.github.io/api/v1/date.json` を取得します。
- 患者情報・医院情報・実データを公開リポジトリや公開ページへ含めないでください。
