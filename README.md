## 動作確認方法

### 重要：確認対象

正式な入口ファイルは `index.html` です。
過去に使っていた旧HTML名は、現在の入口として案内しません。

公開環境の有無は、このリポジトリ内のファイルだけでは確認できません。
ローカル確認では、対象ブランチのファイルを取得して `index.html` をブラウザで開いてください。

1. 対象ブランチの内容を取得する
2. `index.html` をブラウザで開く
3. **Ctrl+F5（強制再読み込み）**してから確認する

### 保存と外部通信

- 受注データは `state.orders` に保持し、同一タブの `sessionStorage` (`dwo_session_orders_v1`) へ一時同期します。再読み込み時は検証後に復元しますが、タブ/ブラウザ終了後の長期保存は行いません。
- 受注が1件以上ある時は、受注管理画面に一時受注の消失警告を表示します。
- 対応ブラウザでは `beforeunload` も有効化しますが、iPad Safariなど標準ダイアログを表示しない環境があります。`sessionStorage` が利用できない場合はページ内メモリ + 消失警告へ安全側にフォールバックします。
- 手書き線とクラスプ位置は localStorage に保存されます。
- 納期カレンダーは日本の祝日判定のため `https://holidays-jp.github.io/api/v1/date.json` を取得します。
- 紙指示書画像・OCR候補はブラウザ内で一時処理し、外部OCR/AI/Firebaseへ送信しません。
- 患者情報・医院情報・実データを公開リポジトリや一時テストURLへ含めないでください。

### 動作確認チェックリスト

- [ ] 医院側入力からこのページの受注一覧へ反映できるか
- [ ] 一時受注の消失警告が表示されるか
- [ ] 受注タブが表示されるか
- [ ] 受付 / 受付取消が動くか
- [ ] 詳細表示が動くか
- [ ] 納品連携JSONを作成できるか
- [ ] PDF出力が動くか
- [ ] Console に赤エラーが出ないか

※ `file://` 起動時のChrome制限系警告（CORSなど）は、確認内容に応じてローカルHTTP previewを使用してください。
